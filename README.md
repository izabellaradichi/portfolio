# Izabella Radichi — Portfólio

Site pessoal de Izabella Radichi, UX Writer e Designer Conversacional, com 15+ anos de trajetória entre atendimento, suporte técnico e produto, 5 deles em chatbots e IA conversacional.

**[Acessar o site](https://portfolio.radichiizabella.workers.dev/)**

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Home: apresentação, trajetória, cases, artigos, ferramentas e experiência |
| `redesenhar-evoluir-criar.html` | Case real: *Redesenhar, evoluir, criar*, a assistente conversacional de uma rede de shopping centers (2021–2026) |
| `squadtrip.html` | SquadTrip: aplicação web para planejar viagens em grupo, criada com IA (projeto pessoal) |
| `uaibot.html` | UaiBot: chatbot de turismo com RAG, feito no n8n com OpenAI e Telegram (projeto de estudo) |
| `notas-fiscais.html` | Automação no n8n que organiza notas fiscais recebidas pelo Telegram (projeto de curso) |
| `curriculo.html` | Currículo completo, com link para download em PDF |

## Estrutura

```
index.html, redesenhar-evoluir-criar.html, curriculo.html, squadtrip.html, uaibot.html, notas-fiscais.html
support.js     → script que monta as páginas no navegador
assets/        → foto
thumbs/        → capas dos cases na home
redesenhar-evoluir-criar/ → imagens e gifs do case real
squadtrip/     → vídeo e telas do SquadTrip
uaibot/        → vídeo e fluxo do UaiBot
notas-fiscais/ → vídeo do case de notas fiscais
```

## Como rodar localmente

Abra o `index.html` no navegador. Não há build nem dependências para instalar, mas as páginas carregam bibliotecas da internet, então é preciso estar conectado.

## Deploy

Publicado no Cloudflare Workers, conectado a este repositório. Cada commit na branch `main` atualiza o site.
